# Skarbiec

Personal wealth-management web app and a deliberate microservices learning project — .NET 10 (5 services + YARP gateway), Angular 22, PostgreSQL (db-per-service), RabbitMQ + MassTransit v8, orchestrated locally with .NET Aspire. See `skarbiec-plan/` for vision, architecture, domain model, roadmap, backlog and ADRs; see `CLAUDE.md` for commands and conventions.
